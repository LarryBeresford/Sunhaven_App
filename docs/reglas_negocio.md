# Reglas de negocio

## Nómina y asistencia

1. Solo las enfermeras de turno fijo, excluyendo supervisoras, pueden generar
   retardos biométricos.
2. Turno día: hora límite de entrada 08:15. Turno noche: 20:15.
3. Una entrada de personal nocturno antes de las 14:00 no se evalúa como
   retardo del turno nocturno.
4. Los checadores especiales no generan retardos.
5. Una incidencia grave elimina los bonos de puntualidad, uniforme y
   administración.

## Pendiente de definición

La regla para personal evaluado solo por horas semanales requiere una lista
definitiva de colaboradores y la fórmula de cálculo antes de implementarse.
